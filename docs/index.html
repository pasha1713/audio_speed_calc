Возможности

Анализ звука

  • 6 алгоритмов выделения границ гармоник в спектрограмме:
    1. 1.dB — абсолютный порог в dB
    2. 2.Пал — индекс палитры
    3. 3.Отн — относительно пика
    4. 4.Шум — адаптивный от шума
    5. 5.-3dB — половинная мощность
    6. 6.RMS — RMS-интегрирование
  • Выбор 5-й и 4-й гармоник кликом мыши прямо по спектрограмме.
  • Расчёт мгновенной скорости по шагам с оценкой погрешности ±V.
  • Интерактивный зум, история переходов, сохранение позиций.

GPS-сравнение

  • Автоизвлечение GPS-меток из .ts-файла:
    • основной способ — exiftool -ee3;
    • резервный — прямой бинарный разбор потока PID 0x0300 (встроен в основной скрипт).
  • Автоматический поиск запаздывания GPS относительно аудио через кросс-корреляцию (по положительной корреляции Пирсона).
  • Ручная переустановка лага через gps_lag_override в конфиге.
  • Наложение GPS-скорости на спектрограмму в единицах Гц (H5 / H4).
  • Полный диагностический лог по GPS-лагу (*_gps_lag_diag.log + CSV).

Визуализация

  • Спектрограмма в режимах time (pcolormesh) и power (contourf).
  • Сетка гармоник, полосы H5/H4, линии min/max, «трубы» по шагам.
  • Подписи пиков скорости и маркеры Vmax/Vmin в видимом окне.
  • Экспорт PNG со штампом (версия, MD5, время, путь).

Отчёты

  • <file>_speed_report_algoN.txt — пошаговый расчёт с формулами и подстановками, сведения о системе, диске и скрипте.
  • Включает сводку по всем запущенным алгоритмам за сеанс.

Как это работает

Двигатель внутреннего сгорания возбуждает акустические колебания на частоте, пропорциональной оборотам коленвала: 

f_осн = n · cyl / (60 · stroke)

где n — обороты (об/мин), cyl — число цилиндров, stroke — тактность (2 для 4-тактного, 1 для 2-тактного).

Спектрограмма .ts-дорожки содержит чёткие пики на гармониках основной частоты. Программа отслеживает положение 5-й и 4-й гармоник во времени, вычисляет среднюю фундаментальную частоту и пересчитывает её в скорость по формуле: 

V = 0.377 · Rk · n / (Io · Ik)

где Rk — эффективный радиус качения колеса, Io — главная пара, Ik — передаточное число КПП.

Установка

1. Клонирование

git clone https://github.com/<ваш-логин>/audio_speed_calc.git
cd audio_speed_calc

2. Установка Python-зависимостей

pip install -r requirements.txt

Если pip не в PATH — используйте python -m pip install -r requirements.txt.

3. Установка внешних программ

Windows

  1. ffmpeg + ffprobe — скачать ffmpeg-release-essentials.zip с gyan.dev или ffmpeg-master-latest-win64-gpl.zip с BtbN/FFmpeg-Builds. Распаковать ffmpeg.exe и ffprobe.exe в папку bin\ рядом со скриптом или добавить в системный PATH.
  2. exiftool (опционально) — скачать exiftool-XX.XX_64.zip с exiftool.org. Распаковать содержимое в папку bin\. Файл exiftool(-k).exe переименовать в exiftool.exe.

Linux (Debian/Ubuntu)

sudo apt install ffmpeg libimage-exiftool-perl python3-tk

Linux (Fedora)

sudo dnf install ffmpeg perl-Image-ExifTool python3-tkinter

macOS (Homebrew)

brew install ffmpeg exiftool python-tk

4. Проверка установки

python audio_speed_calc.py путь/к/файлу.TS

В консоли должны появиться строки вида:

ffmpeg: C:\...\bin\ffmpeg.exe
ffprobe: C:\...\bin\ffprobe.exe
Файл: 2026_0602_050735.TS  длительность: 180.000 сек (ffprobe (video stream))
GPS: 176 меток (exiftool)

Если ffmpeg не найден — программа выйдет с подсказкой. Это значит, что ffmpeg.exe / ffprobe.exe не лежат ни рядом со скриптом, ни в bin/, ни в PATH.

Быстрый старт

python audio_speed_calc.py path/to/DCIM/2026_0602_050735.TS

При первом запуске:

  1. Программа извлечёт аудио и построит спектрограмму.
  2. Откроется консольный запрос параметров автомобиля (Enter — согласиться с сохранёнными, n — ввести новые).
  3. Кликните мышью по 5-й гармонике и 4-й гармонике.
  4. Нажмите кнопку алгоритма (1.dB … 6.RMS) или клавишу 1–6.
  5. Опционально: GPS→H5 / GPS→H4 — наложить GPS-скорость.
  6. Клавиша S — сохранить отчёт, P — сохранить PNG.

Формулы

f5 = H5ц / 5
f4 = H4ц / 4
f  = (f5 + f4) / 2

n  = 60 · f · stroke / cylinders
Rk = 0.85 · P · H / 1e5 + 0.0127 · R
V  = 0.377 · Rk · n / (Io · Ik)

df = ((H5max-H5min)/5 + (H4max-H4min)/4) / 2 / 2
dn = 60 · df · stroke / cylinders
dV = 0.377 · Rk · dn / (Io · Ik)

где:

  • P — ширина шины, мм
  • H — профиль шины, %
  • R — посадочный диаметр, дюймы
  • Io — главная пара
  • Ik — передаточное число КПП

Скрипты

audio_speed_calc.py

Основной модуль: GUI на matplotlib + tkinter, весь расчёт скорости, работа с GPS и системная диагностика.

Ключевые точки входа:

  • main() — CLI-парсер аргументов, подготовка конфига, запуск;
  • AudioSpeedAnalyzer.run() — основной цикл;
  • _on_run() — расчёт по выбранному алгоритму;
  • _draw_speed_overlay() / _draw_speed_labels() — GPS-оверлей;
  • write_gps_lag_diag() — диагностический лог по GPS-лагу.

Функции работы с GPS (внутри модуля):

  • extract_gps() — унифицированная точка входа;
  • parse_gps_exiftool() — exiftool -ee3 -n;
  • parse_ts_gps() — прямой бинарный разбор PID 0x0300;
  • find_gps_lag() — кросс-корреляция аудио и GPS;
  • gps_to_relative_time() — перевод в относительные секунды;
  • find_gps_window_points() — выборка GPS-точек в окне анализа.

sys_fingerprint.py

  • md5_file() — FIPS-совместимый MD5;
  • get_computer_info() — ЦП, ОС, пользователь, CPU S/N;
  • get_disk_info() — ФС, метка тома, модель и серийник диска (через WinAPI DeviceIoControl, wmic, PowerShell);
  • get_script_info() — размер, mtime, MD5 скрипта.

FAQ

Q: ffmpeg не найден.

Положите ffmpeg.exe и ffprobe.exe в папку bin/ рядом со скриптом или добавьте в системный PATH. На Linux/macOS: 

sudo apt install ffmpeg      # Debian/Ubuntu
brew install ffmpeg          # macOS

Q: GPS-корреляция < 0.5.

Результат недостоверен. Варианты:

  • выбрать окно с выраженным разгоном/торможением;
  • проверить правильность ввода передач КПП и главной пары;
  • задать gps_lag_override вручную в JSON-конфиге;
  • открыть <base>_gps_lag_diag.log и посмотреть секции 4, 5, 10.

Q: «нет динамики» в диагностическом логе.

Обе скорости (аудио и GPS) почти постоянны в окне анализа. Корреляция двух плоских сигналов ненадёжна. Выберите другой отрезок с разгоном или торможением.

Q: Много гармоник в спектрограмме — как выбрать нужные.

Начните с 5-й — обычно это самая низкая чёткая линия в диапазоне f0 * 5. Кликните по её середине. Программа сама переключится в режим выбора 4-й гармоники.

Q: Tkinter отсутствует на Linux.

Установите отдельным пакетом:

sudo apt install python3-tk        # Debian/Ubuntu
sudo dnf install python3-tkinter   # Fedora
sudo pacman -S tk                  # Arch

Q: Как задать оффсет GPS вручную.

В <base>_config.json установите:

"gps_lag_override": 1.5

Значение в секундах. Программа пометит его как (OVR) в статусной строке.

Q: Программа запускается, но окно пустое / без кнопок.

Скорее всего, конфликт версий matplotlib. Убедитесь, что установлен matplotlib >= 3.4: 

pip install --upgrade matplotlib

Q: Как поменять частотный диапазон спектрограммы.

Поля Fmin / Fmax в нижней панели ввода. Или править freq_min / freq_max в JSON-конфиге до запуска.

Q: Что такое gps_trim_fft_edges.

При корреляции аудио-сигнала края FFT-окна искажены (hanning-окно не даёт ровных значений на границах). Флаг включает обрезку краёв на длину одного FFT-окна (≈ 0.73 с при 32768 сэмплов и 30 fps). По умолчанию — true.

Q: Как разобрать GPS из .ts-файла без запуска GUI.

В основном скрипте есть функции extract_gps() и parse_ts_gps(). Можно вызвать их из Python-REPL: 

from audio_speed_calc import extract_gps, gps_to_relative_time
pts, method = extract_gps('путь/к/файлу.TS')
for t, v, lat, lon, brg in gps_to_relative_time(pts):
    print(f'{t:7.1f}  {v:7.1f}  {lat:9.5f}  {lon:9.5f}  {brg:6.1f}')
