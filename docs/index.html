1. Назначение и область применения

1.1. Назначение

Программа audio_speed_calc предназначена для определения скорости движения транспортного средства (ТС) путём инструментального анализа звукового ряда видеофонограмм, полученных с автомобильных видеорегистраторов. Метод основан на выделении гармонических составляющих шума работающего двигателя внутреннего сгорания (ДВС) и последующем пересчёте частоты рабочего цикла двигателя в скорость движения ТС с учётом передаточных чисел трансмиссии и геометрических параметров шин.

Программа позволяет:

  • определять частоту вращения коленчатого вала двигателя (об/мин) по звукозаписи;
  • рассчитывать скорость движения ТС в любой момент видеофонограммы;
  • строить графики зависимости скорости от времени;
  • сопоставлять результаты с GPS-данными, содержащимися в видеофайле (при наличии);
  • формировать отчёты для судебно-экспертной практики.

1.2. Область применения

  • Судебная экспертиза ДТП — определение скорости ТС в момент, предшествующий происшествию, особенно в условиях ограниченной видимости или отсутствия ориентиров на местности.
  • Автотехническая экспертиза — проверка показаний участников ДТП.
  • Научно-исследовательские задачи — анализ акустических характеристик работы ДВС.

1.3. Ограничения

  • Метод применим для ТС с механической коробкой передач (МКПП). Для автоматических коробок (АКПП) требуется дополнительное определение номера включённой передачи.
  • Точность зависит от качества звукозаписи и шумовой обстановки в салоне.
  • Требуется знание передаточных чисел КПП и главной передачи, а также маркировки шин.

2. Теоретические основы метода

2.1. Физическая сущность

Микрофон видеорегистратора фиксирует акустические колебания, возникающие при работе ДВС. Наиболее выраженной гармонической составляющей является шум выпуска — периодический сигнал, частота которого равна частоте рабочего цикла двигателя.

Для четырёхтактного двигателя полный рабочий цикл (впуск, сжатие, рабочий ход, выпуск) совершается за два оборота коленчатого вала. Для двухтактного — за один оборот.

2.2. Основные формулы

Частота вращения двигателя (об/мин):

n = 120 · f / k (1)

где n — частота вращения коленчатого вала, об/мин; f — частота рабочего цикла двигателя (гармоники), Гц; k — количество цилиндров (для четырёхтактного двигателя).

Скорость движения ТС (км/ч):

V = 0,377 · rk · n / (i0 · ik) (2)

где V — скорость, км/ч; rk — радиус качения ведущих колёс, м; n — частота вращения двигателя, об/мин; i0 — передаточное число главной передачи; ik — передаточное число включённой передачи КПП.

Радиус качения колеса (м):

rk = 10−5 · λ · P · H + 0,0127 · R (3)

где λ — коэффициент смятия шины (0,85–0,90 для диагональных; 0,80–0,85 для радиальных); P — ширина протектора шины, мм; H — профиль шины (высота в % от ширины); R — посадочный диаметр, дюймы.

2.3. Определение номера передачи

При наличии на видеофонограмме момента переключения передачи номер включённой передачи определяется по отношению частот:

nK+1 / nK = iK+1 / iK (4)

Например, при переключении с I на II передачу частота гармоники меняется в 1,74–1,75 раза, что соответствует отношению передаточных чисел.

4. Установка

4.1. Установка Python-зависимостей

pip install -r requirements.txt

Содержимое requirements.txt:

numpy>=1.20
matplotlib>=3.4

4.2. Установка внешних программ

Windows

  1. Скачайте ffmpeg с gyan.dev.
  2. Распакуйте ffmpeg.exe и ffprobe.exe в папку bin\ рядом со скриптом.
  3. (Опционально) Скачайте exiftool с exiftool.org и распакуйте в ту же папку.

Linux (Debian/Ubuntu)

sudo apt install ffmpeg libimage-exiftool-perl python3-tk

Linux (Fedora)

sudo dnf install ffmpeg perl-Image-ExifTool python3-tkinter

macOS (Homebrew)

brew install ffmpeg exiftool python-tk

4.3. Проверка установки

python audio_speed_calc.py --help

Затем запустите программу на тестовом файле. В консоли появится запрос параметров автомобиля (рис. 1).

Совет. Параметры автомобиля считываются из <base>_config.json. Если значения верны, нажмите Enter — программа продолжит работу. Если нужны другие параметры, нажмите n и введите их вручную. Введённые значения действуют только в текущей сессии; для сохранения в файл — клавиша S в окне программы.

5. Быстрый старт

Базовая команда запуска:

python audio_speed_calc.py путь/к/файлу.TS

Для сохранения всего текстового вывода в файл (удобно для судебной практики — отчёт формируется автоматически):

python audio_speed_calc.py путь/к/файлу.TS 1>rez.txt

При первом запуске (см. рис. 1):

  1. Программа извлечёт аудио и построит спектрограмму.
  2. Откроется консольный запрос параметров автомобиля.
  3. Нажмите Enter (согласиться с параметрами из конфига) или n (ввести новые).
  4. В окне программы кликните мышью по 5-й гармонике (обычно 50–100 Гц) и 4-й гармонике.
  5. Нажмите кнопку алгоритма (1.dB … 6.RMS или клавишу 1–6).
  6. Изучите результаты в консоли и на графике (см. рис. 2).
  7. Нажмите A («Применить»), чтобы зафиксировать результат в истории.

6.4. Применение правок (Apply-модель)

Программа использует Apply-модель работы с историей:

  • Все изменения (зум, диапазон, гармоники, параметры) накапливаются в памяти.
  • История не пополняется автоматически при каждом действии.
  • Для фиксации изменений нажмите «Применить» (клавиша A).
  • Индикатор Ист: N/M * показывает наличие неприменённых правок.

Маркер неприменённых правок * хорошо виден в статусной строке на рис. 2 — например, запись Ист: 1/3 без звёздочки означает, что текущее состояние уже зафиксировано в истории (запись №1 из 3).

Внимание. Если вы изменили диапазон/гармоники и нажали «Назад» без применения, программа спросит: «Применить изменения? Да / Нет / Отмена».

  • Да — все накопленные правки фиксируются одной записью, затем происходит шаг назад.
  • Нет — правки не фиксируются, шаг назад выполняется (изменения будут потеряны).
  • Отмена — ничего не происходит, вы остаётесь на месте.

7. Логика расчёта и формулы

7.1. Последовательность расчёта

  1. Извлечение аудио из .ts-файла через ffmpeg.
  2. Построение спектрограммы (БПФ, окно Ханна).
  3. Выбор гармоник H5 и H4 кликом мыши.
  4. Отслеживание гармоник по кадрам.
  5. Расчёт частоты f = (f5/5 + f4/4) / 2.
  6. Расчёт оборотов n = 120 · f / k.
  7. Расчёт скорости V = 0,377 · rk · n / (i0 · ik).

7.2. Алгоритмы выделения границ

АлгоритмМетод
1.dBАбсолютный порог в dB
2.ПалИндекс палитры
3.ОтнОтносительный от пика
4.ШумАдаптивный от шума
5.-3dBПоловинная мощность
6.RMSRMS-интегрирование

7.3. Калибровка GPS

Если в видеофайле содержатся GPS-метки, программа:

  1. Извлекает их через exiftool -ee3 -n.
  2. Вычисляет запаздывание GPS относительно аудио методом кросс-корреляции.
  3. Калибрует результат по самому длинному интервалу из истории.

Приложение А. Пример расчёта

А.1. Исходные данные

ТСлегковой автомобиль, 4 цилиндра, 4-тактный
Шины235/70 R16
Цилиндров4
Передаточные числа i0 = 4,875; ik = 0,802
Частота гармоники H5504,6 Гц
Частота гармоники H4446,7 Гц

А.2. Расчёт

1. Частота рабочего цикла (среднее двух гармоник):

f5 = 504,6 / 5 = 100,92 Гц
f4 = 446,7 / 4 = 111,68 Гц
f  = (100,92 + 111,68) / 2 = 106,3 Гц

2. Обороты двигателя:

n = 120 · 106,3 / 4 = 3189 об/мин

3. Радиус качения колеса:

r_k = 10⁻⁵ · 0,85 · 235 · 70 + 0,0127 · 16 = 0,343 м

4. Скорость движения:

V = 0,377 · 0,343 · 3189 / (4,875 · 0,802) ≈ 105,5 км/ч

А.3. Результат

Скорость ТС: ≈ 105,5 км/ч.

Средняя по программе: Vср = 106,3 км/ч; по GPS: Vgps ср = 105,4 км/ч. Расхождение — менее 1 %, что подтверждает корректность расчёта.

А.4. Определение номера передачи

Частоты гармоник на разных передачах (пример):

Передача Частота, Гц Отношение к предыдущей Отношение передаточных чисел
I92——
II5392/53 ≈ 1,741,75
III5687/56 ≈ 1,581,54
IV6892/68 ≈ 1,351,36

Совпадение отношений частот с отношениями передаточных чисел подтверждает правильность определения номера включённой передачи.
