audio_speed_calc

Расчёт скорости автомобиля по звуку двигателя из .ts-видеофрагментов

Python 3.8+ MIT License v0.53.5 Windows · Linux · macOS

Скрипт извлекает аудиодорожку из .ts-файла, строит спектрограмму, находит частоты 5-й и 4-й гармоник звука двигателя, переводит их в обороты коленвала и вычисляет скорость через параметры трансмиссии. Дополнительно подтягивает GPS-скорость из телеметрии того же файла — для перекрёстной проверки и калибровки.

Возможности #

Спектрограмма

Два режима отображения — time (pcolormesh) и power (contourf).

6 алгоритмов

dB-порог, индекс палитры, относительный от пика, адаптивный от шума, −3 dB, RMS.

Суббинная интерполяция

Точность частоты выше шага БПФ — параболическая подгонка пика.

Автотрекинг гармоник

H5 и H4 отслеживаются по кадрам с адаптивным поиском.

История зума

До 50 состояний, сохраняется в конфиг, восстанавливается при переходах.

GPS-оверлей

Кривые GPS-скорости, откалиброванные через Vref выбранных H5/H4.

Подписи пиков

Для всех активных источников — GPS и реальных треков по гармоникам.

Оценка погрешности

±V на каждом шаге и в итоговой сводке.

Отчёт с формулами

Текстовый файл с подстановками всех формул на каждом шаге.

PNG со штампом

MD5 скрипта, дата, имя файла — в левом верхнем углу.

Как это работает #

  1. Двигатель издаёт звук, основная частота которого пропорциональна оборотам коленвала.
  2. Обороты коленвала связаны со скоростью через передаточное отношение коробки, главной пары и радиус качения шины.

Формулы, используемые в скрипте:

f0 = (H5 / 5 + H4 / 4) / 2              # среднее фундаментальной частоты
n  = 60 · f0 · stroke / cylinders        # об/мин коленвала
Rk = 0.85 · P · H / 100000 + 0.0127 · R  # радиус качения шины, м
V  = 0.377 · Rk · n / (Io · Ik)          # км/ч
ОбозначениеЧто это
H5, H4частоты 5-й и 4-й гармоник звука, Гц
strokeтактность (2 для 4-тактного, 1 для 2-тактного)
cylindersчисло цилиндров
P, H, Rширина, профиль и посадочный диаметр шины
Ioпередаточное число главной пары
Ikпередаточное число текущей передачи КПП
Формулы оценки погрешности 
df = ((H5max − H5min) / 5 + (H4max − H4min) / 4) / 4
dn = 60 · df · stroke / cylinders
dV = 0.377 · Rk · dn / (Io · Ik)

Требования #

  • Python 3.8+
  • ffmpeg и ffprobe — обязательны
  • exiftool — опционально (извлечение GPS через метаданные)

Python-зависимости:

numpy
matplotlib
Важно: модуль sys_fingerprint.py должен лежать рядом со скриптом — используется для штампа в PNG и отчётах.

Установка #

git clone https://github.com/<ваш-логин>/audio_speed_calc.git
cd audio_speed_calc

pip install numpy matplotlib

ffmpeg / ffprobe — один из вариантов:

  • Windows: положить ffmpeg.exe и ffprobe.exe рядом со скриптом или в подпапку bin/.
  • Linux / macOS: sudo apt install ffmpeg / brew install ffmpeg — скрипт найдёт их через PATH.

exiftool — по желанию, тем же способом.

Использование #

python audio_speed_calc.py path/to/fragment.ts

Дополнительно:

python audio_speed_calc.py fragment.ts --config my_config.json

Если --config не задан, скрипт ищет <base_ts>_config.json рядом с видеофайлом. При первом запуске настройки берутся из audio_speed_config.json (если есть) и копируются в per-file конфиг.

Типичный сценарий

  1. Запустить скрипт — откроется окно со спектрограммой.
  2. Выделить диапазон анализа — drag по горизонтали.
  3. Нажать «5я гармоника» и кликнуть по 5-й гармонике в спектре.
  4. Нажать «4я гармоника» и кликнуть по 4-й гармонике.
  5. Выбрать алгоритм (1–6) или нажать цифру на клавиатуре.
  6. Смотреть результат в статусной строке и в сохранённом отчёте.
  7. P — сохранить PNG, S — сохранить конфиг.

GPS-скорость #

Скрипт пытается извлечь GPS-метки двумя способами (в порядке приоритета):

  1. exiftool — -ee3 -n, учитывается GPSSpeedRef (K / M / N).
  2. Прямой бинарный разбор TS — PID 0x0300, поиск PES-заголовка 00 00 01 BF.

Найденные метки приводятся к относительному времени (от первой точки) и участвуют в:

  • кросс-корреляции для оценки запаздывания GPS относительно аудио (диапазон −5…+5 с, шаг 0.1 с);
  • сравнении Vср аудио и Vgps ср;
  • оверлее GPS→H5 и GPS→H4 — кривые GPS-скорости, отмасштабированные через Vref выбранных гармоник.
Если корреляция ниже 0.5, скрипт предупреждает о недостоверности и предлагает задать gps_lag_override в конфиге.
