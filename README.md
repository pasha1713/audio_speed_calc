# audio_speed_calc

**Расчёт скорости автомобиля по звуку двигателя из .ts-видеофрагментов.**

Скрипт извлекает аудиодорожку из `.ts`-файла, строит спектрограмму, находит
частоты 5-й и 4-й гармоник звука двигателя, переводит их в обороты коленвала
и вычисляет скорость через параметры трансмиссии. Дополнительно подтягивает
GPS-скорость из телеметрии того же файла (через `exiftool` или бинарный
разбор TS-потока) — для перекрёстной проверки и калибровки.

## Возможности

- **Спектрограмма** с двумя режимами отображения — `time` (pcolormesh)
  и `power` (contourf).
- **6 алгоритмов** выделения границ гармоник (dB-порог, индекс палитры,
  относительный от пика, адаптивный от шума, половинная мощность, RMS).
- **Суббинная интерполяция** пиков — точность частоты выше шага БПФ.
- **Автотрекинг** 5-й и 4-й гармоник по кадрам с адаптивным поиском.
- **Настраиваемый диапазон анализа** — drag-выделение по времени.
- **История зума** (до 50 состояний) с сохранением в конфиг и
  восстановлением параметров при переходах вперёд/назад.
- **GPS-оверлей**: кривые GPS-скорости, откалиброванные через
  V_ref выбранных H5/H4.
- **Подписи пиков и экстремумов** скорости для всех активных источников
  (GPS и реальные треки по гармоникам) — каждый своим цветом.
- **Оценка погрешности**: ±V на каждом шаге и в итоге.
- **Сводка по алгоритмам** — сравнение Vср/разброса между запущенными
  алгоритмами.
- **Отчёт** в текстовом виде с подстановками всех формул для каждого шага.
- **PNG-скриншоты** со штампом (MD5 скрипта, дата, имя файла).
- **Кросс-платформенность**: Windows / Linux / macOS.

## Как это работает

Физика процесса:

1. Двигатель издаёт звук, основная частота которого пропорциональна
   оборотам коленвала.
2. Обороты коленвала связаны со скоростью через передаточное отношение
   коробки, главной пары и радиус качения шины.

Формулы, используемые в скрипте:

```
f0 = (H5 / 5 + H4 / 4) / 2                 # среднее фундаментальной частоты
n  = 60 · f0 · stroke / cylinders           # об/мин коленвала
Rk = 0.85 · P · H / 100000 + 0.0127 · R     # радиус качения шины, м
V  = 0.377 · Rk · n / (Io · Ik)             # км/ч
```

где:

| Обозначение | Что это |
|---|---|
| `H5`, `H4` | частоты 5-й и 4-й гармоник звука, Гц |
| `stroke` | тактность (2 для 4-тактного, 1 для 2-тактного) |
| `cylinders` | число цилиндров |
| `P`, `H`, `R` | ширина, профиль и посадочный диаметр шины |
| `Io` | передаточное число главной пары |
| `Ik` | передаточное число текущей передачи КПП |

Погрешность оценки скорости:

```
df = ((H5max − H5min) / 5 + (H4max − H4min) / 4) / 4
dn = 60 · df · stroke / cylinders
dV = 0.377 · Rk · dn / (Io · Ik)
```

## Использование

```bash
python audio_speed_calc.py path/to/fragment.ts
```

Дополнительные параметры:

```bash
python audio_speed_calc.py fragment.ts --config my_config.json
```

Если `--config` не задан, скрипт ищет `<base_ts>_config.json` рядом
с видеофайлом. При первом запуске настройки берутся из
`audio_speed_config.json` (если он есть) и копируются в
per-file конфиг.

### Типичный сценарий

1. **Запустить скрипт** — откроется окно со спектрограммой.
2. **Выделить диапазон анализа** — drag по горизонтали.
3. Нажать **`5я гармоника`** и кликнуть по 5-й гармонике в спектре.
4. Нажать **`4я гармоника`** и кликнуть по 4-й гармонике.
5. Выбрать **алгоритм** (1–6) или нажать цифру на клавиатуре.
6. Смотреть результат в статусной строке и в сохранённом отчёте.
7. `P` — сохранить PNG, `S` — сохранить конфиг.

## Алгоритмы выделения границ

| № | Название | Идея |
|---|---|---|
| 1 | Абсолютный порог dB | порог = vmin + (цвет/255)·(vmax−vmin) |
| 2 | Индекс палитры | порог = индекс_центра − цвет |
| 3 | Относительный от пика | порог = dB_пика − цвет |
| 4 | Адаптивный от шума | порог = медиана_шума + цвет·σ |
| 5 | Половинная мощность (−3 dB) | спад на `цвет/255·3` dB |
| 6 | RMS-интегрирование | накопление доли мощности от центра |

Полная справка по каждому — по кнопке `?` рядом с алгоритмом.

## GPS-скорость

Скрипт пытается извлечь GPS-метки двумя способами (в порядке приоритета):

1. **exiftool** — `-ee3 -n`, учитывается `GPSSpeedRef` (K / M / N).
2. **Прямой бинарный разбор TS** — PID `0x0300`, поиск PES-заголовка
   `00 00 01 BF`.

Найденные метки приводятся к относительному времени (от первой точки)
и участвуют в:

- **кросс-корреляции** для оценки запаздывания GPS относительно аудио
  (поиск лага в диапазоне −5…+5 с шагом 0.1 с);
- **сравнении** Vср аудио и Vgps ср;
- **оверлее** GPS→H5 и GPS→H4 — кривые GPS-скорости, отмасштабированные
  через V_ref выбранных гармоник.

Если корреляция ниже 0.5, скрипт предупреждает о недостоверности и
предлагает задать `gps_lag_override` в конфиге.

## Конфигурация

Пример ключевых полей конфига:

```json
{
  "freq_min": 20,
  "freq_max": 600,
  "harmonic_5_freq": 285.3,
  "harmonic_4_freq": 228.2,
  "color_steps": 10,
  "time_step": 0.1,
  "peak_search_hz": 5.0,
  "algorithm": 2,
  "sample_rate": 44100,
  "fft_size": 32768,
  "target_fps": 30,
  "cylinders": 4,
  "stroke": 2,
  "tire_width": 235,
  "tire_profile": 70,
  "rim_diameter": 16,
  "final_drive": 4.875,
  "gear_ratio": 0.802,
  "gps_lag_override": null,
  "overlay_mode": 0,
  "spec_mode": "time"
}
```

| Ключ | Смысл |
|---|---|
| `fft_size` | размер окна БПФ (32768 = хорошее разрешение по частоте) |
| `target_fps` | частота кадров спектрограммы (30) |
| `time_step` | шаг расчёта в секундах |
| `peak_search_hz` | полуширина поиска пика гармоники, Гц |
| `gps_lag_override` | ручное запаздывание GPS в секундах (`null` = авто) |
| `spec_mode` | `"time"` или `"power"` |
