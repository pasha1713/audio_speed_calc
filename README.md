## Введение
Программа **audio_speed_calc** реализует методику определения скорости транспортного средства (ТС) по звукозаписям автомобильного видеорегистратора. Метод разработан в ФБУ Челябинская ЛСЭ Минюста России **А.А. Годлевским** и прошёл апробацию ведущими государственными судебными экспертами ФБУ Сибирский РЦСЭ и ФБУ Томская ЛСЭ Минюста России.

## Назначение и область применения

### Назначение
Программа предназначена для определения скорости движения ТС путём инструментального анализа звукового ряда видеофонограмм, полученных с автомобильных видеорегистраторов. Метод основан на выделении гармонических составляющих шума работающего двигателя внутреннего сгорания (ДВС) и последующем пересчёте частоты рабочего цикла двигателя в скорость движения ТС с учётом передаточных чисел трансмиссии и геометрических параметров шин.

### Ограничения
* Метод применим для ТС с **механической коробкой передач (МКПП)**. Для автоматических коробок (АКПП) требуется дополнительное определение номера включённой передачи.
* Точность зависит от качества звукозаписи и шумовой обстановки в салоне.
* Требуется знание передаточных чисел КПП и главной передачи, а также маркировки шин.
* Подписи пиков на графике рисуются с фильтром, предотвращающим их наложение. Пороги фильтра настраиваются (`label_pad_x_frac`, `label_pad_y_frac`).

## Теоретические основы метода

### Основные формулы
Частота вращения двигателя (об/мин):
**n = 60 · f · (2 / k) = 120 · f / k** (1)
где *n* — частота вращения коленчатого вала, об/мин; *f* — частота рабочего цикла двигателя (гармоники), Гц; *k* — количество цилиндров (для четырёхтактного двигателя); 2 — количество оборотов коленчатого вала за один рабочий цикл.

Средняя скорость движения ТС (км/ч):
**V = 3,6 · S_k / T** (2)
где *S_k* — путь, пройденный колесом за один оборот, м; *T* — период вращения колеса, с.

Путь, пройденный колесом за один оборот:
**S_k = 2 · π · r_k** (3)

Период вращения колеса:
**T = 60 · i₀ · i_k / n** (4)
где *i₀* — передаточное число главной передачи; *i_k* — передаточное число включённой передачи КПП.

Итоговая скорость (км/ч):
**V = 0,377 · r_k · n / (i₀ · i_k)** (5)

Радиус качения колеса (м):
**r_k = 10⁻⁵ · λ · P · H + 0,0127 · R** (6)
где λ — коэффициент смятия шины (`tire_deflection_coeff`); *P* — ширина протектора шины, мм; *H* — профиль шины (высота в % от ширины); *R* — посадочный диаметр, дюймы.

## Быстрый старт
```bash
python audio_speed_calc.py path/to/file.TS
```
С сохранением всего текстового вывода в файл:
```bash
python audio_speed_calc.py path/to/file.TS 1>rez.txt
```
1. Программа извлечёт аудио и построит спектрограмму.
2. Нажмите **Enter** (согласиться с параметрами авто) или **n** (ввести новые).
3. В окне кликните мышью по **5-й гармонике** (H5), затем по **4-й гармонике** (H4).
   *Для 4-цилиндрового 4-тактного: при 3000 об/мин H5 ≈ 500 Гц, H4 ≈ 400 Гц.*
4. Нажмите кнопку алгоритма или клавишу **1–6**.
5. Нажмите **A** («Применить»), чтобы зафиксировать результат.

## Логика расчёта и формулы
1. Извлечение аудио из .ts-файла через `ffmpeg`.
2. Построение спектрограммы (БПФ, окно Ханна, fft_size 32768).
3. Выбор гармоник H5 и H4 кликом мыши.
4. Отслеживание гармоник по кадрам (rolling-трекинг пика).
5. Расчёт частоты f = (f5/5 + f4/4) / 2.
6. Расчёт оборотов n = 60 · f · stroke / cylinders.
7. Расчёт скорости V = 0,377 · rk · n / (i0 · ik).

### Алгоритмы выделения границ
| Алгоритм | Метод |
| :--- | :--- |
| 1.dB | Абсолютный порог в dB |
| 2.Пал | Индекс палитры |
| 3.Отн | Относительный от пика |
| 4.Шум | Адаптивный от шума |
| 5.-3dB | Половинная мощность |
| 6.RMS | RMS-интегрирование |

### Типовые ситуации «симптом → параметр»
* **Скорости завышены/занижены:** Правьте `tire_deflection_coeff` по формуле `c_new = c_old * (1 - k/100)`, где k — расхождение в %.
* **Программа не находит гармоники:** Проверьте `freq_min` / `freq_max`. Увеличьте `peak_search_hz` до 10–15, если гармоника дрейфует.
* **Подписи налезают:** Увеличьте `label_pad_x_frac` до 0.12–0.15 или `label_pad_y_frac` до 0.08.
* **dGPS явно неверный:** Задайте `gps_lag_override` вручную (например, `1.5` или `-2.0`).

## Приложение А. Пример расчёта
**Исходные данные:** Шины 235/70 R16; 4 цилиндра; i₀ = 4,875; i_k = 0,802; H5 = 504,6 Гц; H4 = 446,7 Гц.

1. **Частота рабочего цикла:**
   f5 = 504,6 / 5 = 100,92 Гц
   f4 = 446,7 / 4 = 111,68 Гц
   f = (100,92 + 111,68) / 2 = **106,3 Гц**
2. **Обороты:**
   n = 120 * 106,3 / 4 = **3189 об/мин**
3. **Радиус качения:**
   r_k = 10⁻⁵ * 0,84 * 235 * 70 + 0,0127 * 16 = **0,339 м**
4. **Скорость:**
   V = 0,377 * 0,339 * 3189 / (4,875 * 0,802) ≈ **104,3 км/ч**

*При c_def = 0,85 — 105,5 км/ч. Средняя по программе: 105,3 км/ч, по GPS: 105,4 км/ч. Расхождение < 1%.*
